# Arquitetura do MGU

Esta pasta contém a documentação arquitetural vigente da Mentoria Garimpo Urbano.

## Fonte de verdade

O documento principal é:

`Arquitetura-MGU-v3.0.txt`

Ele registra o estado atual da arquitetura, decisões técnicas, ambientes, domínios, regras de negócio, roadmap e histórico das etapas de estabilização.

Sempre que uma alteração de implementação modificar uma decisão arquitetural, regra estrutural ou etapa do roadmap, este documento deve ser atualizado no mesmo ciclo da mudança.
