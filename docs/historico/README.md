# Histórico

Esta pasta preserva documentos de fases anteriores do desenvolvimento do MGU.

Os arquivos aqui mantêm valor histórico e ajudam a entender decisões, implementações e planos anteriores.

## Importante

O conteúdo desta pasta pode descrever:

- estruturas que já foram alteradas;
- branches e commits antigos;
- modelos de dados anteriores;
- domínios ou subdomínios antigos;
- planos de implementação já substituídos;
- regras que não representam mais a arquitetura vigente.

Por isso, estes documentos não devem ser usados como fonte de verdade para novas implementações.

## Fonte de verdade atual

A arquitetura vigente está em:

```text
../arquitetura/Arquitetura-MGU-v3.0.txt
```

Os procedimentos operacionais atuais estão em:

```text
../operacao/
```

Os procedimentos de banco e migrações estão em:

```text
../migracoes/
```
